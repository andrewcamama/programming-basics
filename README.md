# programming-basics

Simple beginner programs in different languages. Each folder has a style program with comments that explain every line, so first-timers can compare how each language looks and runs.

## How to run

| Language   | Command                                            |
|------------|----------------------------------------------------|
| Python     | `python python/hello.py`                           |
| JavaScript | `node javascript/hello.js`                         |
| Java       | `javac java/Hello.java` then `java -cp java Hello` |
| C          | `gcc c/hello.c -o hello` then `./hello`            |
| PHP        | `php php/hello.php`                                |

## How to read the code
- Lines starting with `#` (Python) or `//` (JavaScript, Java, C, PHP) are comments. They explain what the code does.
- Try changing the name or the message, then run it again to see what happens.
- Don't just copy. Type it yourself, it helps you remember.
